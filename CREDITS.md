## jsPDF

**jsPDF 2.5.1** creates the exported PDF documents. It is loaded from its CDN and is distributed under the MIT license.

- Project and licensing: https://github.com/parallax/jsPDF/tree/v2.5.1
- Runtime script: https://cdnjs.cloudflare.com/ajax/libs/jspdf/2.5.1/jspdf.umd.min.js

## Typography and test tooling

- **DM Sans** is an optional Google Fonts stylesheet. The interface has local system-font fallbacks. Source: https://fonts.google.com/specimen/DM+Sans
- **Playwright** is used only for development/browser integration tests and is not shipped as an editor runtime dependency. Project: https://playwright.dev/

## Release examples

The screenshots, PNG exports, original four-page PDF, and print photographs in [docs](docs/) were supplied by Rokoel for the Open Map Creator v1.4.0 documentation and release. The photographs show a measured 2.5 cm cell and a map assembled from four paper sheets.

Publication copies of the photographs have camera/GPS metadata removed without changing their decoded pixels. The supplied PNGs and PDF are copied without modification.
