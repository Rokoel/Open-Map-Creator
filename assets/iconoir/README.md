# Iconoir icons

Selected unmodified regular SVG paths from [Iconoir v7.12.1](https://github.com/iconoir-icons/iconoir/tree/v7.12.1), combined into an SVG symbol sprite.

Copyright (c) 2021 Luca Burgio. Used under the [MIT license](LICENSE.txt). No Iconoir JavaScript, React, Vue, or font package is needed.

Included icons: cursor-pointer, edit-pencil, erase, grid-plus, light-bulb, sun-light, half-moon, undo, redo, download, upload, plus, trash, eye, eye-closed, arrow-up, arrow-down, refresh, lock, lock-slash, map, frame, floppy-disk, link, link-slash, media-image, minus, multiple-pages.
